# ADR 索引

本文档是 `docs/adr/` 下架构决策记录（ADR）的导航表，用于快速定位某主题的**当前有效决策**。

- **状态**：`有效` 表示该决策当前生效；`部分取代` 表示部分条款已被后续 ADR 取代（对应文件内已标注"已被 XX 取代"）；`已取代` 表示整体失效。
- 术语与语义的当前权威定义在 [CONTEXT.md](../../CONTEXT.md)（词表），ADR 记录的是决策的历史、理由与被驳回方案。

**阅读指引**：
- 想了解当前生效语义 → 读 [CONTEXT.md](../../CONTEXT.md) 词表，词条已引用对应 ADR 编号。
- 想了解某主题的完整决策史 → 从表中最新的"有效"行出发，沿"取代"关系回溯。
- 新增决策 → 追加编号最大的下一篇 ADR，并更新本表与本表行内状态。
